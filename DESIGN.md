# Forklight design direction

Forklight is an editorial decision instrument, not a dashboard. Its visual language borrows from folded paper, print registration marks, and counterfactual branching diagrams. The page uses an ivory field, cobalt structure, vermilion calls to action, and deliberately oversized type.

The silhouette is a continuous vertical broadsheet: a typographic cover, an animated folding fan, a diagonal thesis, a circular decision compass, and a banded input instrument. It avoids cards, skeleton loaders, side-panel dashboards, and the dark neon visual language used by CausalLoom.
